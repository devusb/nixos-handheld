# RG28XX Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Anbernic RG28XX (Allwinner H700) as a second supported handheld alongside the R36H, building a flashable SD card image speculatively (no hardware in hand).

**Architecture:** Mirror the existing `socs/` / `handhelds/` / `modules/` / `pkgs/` separation. Add an H700 SoC module, a kernel + DTB + U-Boot package set for the new SoC family, an RG28XX device directory, a new opt-in fake-suspend NixOS module (because H700 mainline has no real S3), and wire it all into the flake.

**Tech Stack:** NixOS unstable, mainline Linux 6.x via `linuxManualConfig` + static defconfig, mainline U-Boot (vendored as a ROCKNIX-provided blob for v1), Allwinner H700 (`sun50i-h616` family in mainline), Mali-G31 via Panfrost (Mesa), shell scripting for fake-suspend (`bats` for unit tests, `shellcheck` for lint).

**Spec:** `docs/superpowers/specs/2026-05-15-rg28xx-port-design.md`

### Additional notes from execution (2026-05-25)

- The first kernel build surfaced three Kconfig deps that needed explicit `=y`: `CONFIG_EXTCON`, `CONFIG_NOP_USB_XCEIV`, `CONFIG_PHY_SUN4I_USB`. MUSB_SUNXI depends on all three but selects none. The fixed defconfig now sets them explicitly.
- `CONFIG_SUN4I_GPADC` is intentionally dropped: H700 reads its joystick ADC through the AXP717 (`CONFIG_AXP20X_ADC`), and `SUN4I_GPADC`'s Kconfig requires `MFD_SUN4I_GPADC || MACH_SUN8I`, neither of which apply on aarch64 H700.
- The plan's amendment #5 was wrong about rocknix-joypad: mainline `sun50i-h700-anbernic-rg35xx-2024.dts` wires only `gpio-keys` for buttons; joystick-ADC bindings live in ROCKNIX's out-of-tree patches. This is now correctly documented in `docs/rocknix-h700-notes.md` and called out as a hardware-bring-up follow-up in `docs/rg28xx-bringup.md` Section 4.

### Amendments to original plan based on Task 1 research

1. **Task 2 (U-Boot) — scope expanded.** Originally vendored a ROCKNIX prebuilt blob. ROCKNIX builds U-Boot from source (mainline `v2025.07-rc3`, defconfig `anbernic_rg35xx_h700_defconfig`, ATF for `sun50i_h616`), so no blob exists in their git tree. User decision (2026-05-16): build from source as a Nix derivation now. New Task 2 needs:
   - `pkgs/u-boot-rg28xx/default.nix` using nixpkgs' `buildUBoot` helper with `defconfig = "anbernic_rg35xx_h700"`
   - An ATF derivation (or reuse nixpkgs' `pkgs.armTrustedFirmwareAllwinner` if it covers H616) — needs verification
   - Output: a single `u-boot-sunxi-with-spl.bin` artifact suitable for `dd seek=8 bs=1K`
   - **dd offset confirmed: 8 KiB / sector 16** (see notes; from ROCKNIX `bootloader/update.sh`)

2. **Task 4 — completed with one carve-out.** The RG28XX DTS is a tiny overlay on mainline's `sun50i-h700-anbernic-rg35xx-plus.dts`. Mainline v7.0 builds the base file but does NOT define a `&panel` node, so the ROCKNIX panel override is dropped. Re-adding it depends on the panel-driver outcome in Task 8. `pkgs/h700-dtb` is wired against `linuxPackages_latest.kernel` (not `linux-h700`) since only DT bindings are needed; this decouples Task 4 from Task 3.

3. **Task 7 (`socs/h700.nix`) — boot-loader strategy clarified.** ROCKNIX's H700 boot scheme uses a compiled `boot.scr` + fixed-path `dtb.img` on a FAT partition, NOT extlinux. However, mainline U-Boot's `anbernic_rg35xx_h700_defconfig` is built with `CONFIG_DISTRO_DEFAULTS=y`, so its boot env should scan for `extlinux/extlinux.conf` as a fallback. **Plan:** try NixOS's stock `boot.loader.generic-extlinux-compatible` first. If U-Boot doesn't find `extlinux.conf`, fall back to generating a `boot.scr` from `installBootLoader` via `mkimage`. Verify by booting the built image in QEMU sunxi target if possible, or wait for hardware.

4. **Task 8 — new sub-task: panel driver.** RG28XX panel uses `panel-mipi-dpi-spi` (kikuchan98 v2 out-of-tree patchset). Not in mainline v7.0. Options:
   - (a) Add `pkgs/panel-mipi-dpi-spi/` out-of-tree kernel module + a kernel patch to add the `&panel` node to `sun50i-h700-anbernic-rg35xx-2024.dts` (matching ROCKNIX patches 0110 + 0111). Most faithful to ROCKNIX.
   - (b) Wait for the driver to land in mainline — kikuchan98's patchset is marked `v2` and is upstream-bound; check the lkml status before starting.
   - (c) Apply kernel patches *and* embed the `&panel` node in our DTS overlay (no base-DTS patch needed). Cleanest if (a) is too messy.
   
   Choose during Task 8. Until then, the built image will boot but have no display backlight init.

5. **Joypad driver.** `pkgs/rocknix-joypad` (already in tree) is the same kernel module ROCKNIX uses for H700. The DTS bindings in `sun50i-h700-anbernic-rg35xx-2024.dts` (mainline) already wire it. No changes needed beyond enabling the module in Task 8's `default.nix`.

6. **Panel-orientation / display geometry.** 640×480 native landscape (per ROCKNIX device page); no rotation property needed in DTS. Confirmed.

7. **Tests added that aren't in the original plan.** `modules/fake-suspend/tests/test_handheld_fake_suspend.bats` (13 cases) should be wired into `nix flake check` in Task 9 so CI runs them. Note for Task 9: add a `bats-check` derivation that runs the suite in a sandbox.

  ```bash
  #!/usr/bin/env bash
  set -euo pipefail

  DEVICE_NAME="$1"

  resolve_device() {
    for ev_name in /sys/class/input/event*/device/name; do
      if [ "$(cat "$ev_name" 2>/dev/null || true)" = "$DEVICE_NAME" ]; then
        # /sys/class/input/eventN/device/name -> /dev/input/eventN
        evnum=$(echo "$ev_name" | sed -E 's|.*/event([0-9]+)/.*|\1|')
        echo "/dev/input/event${evnum}"
        return 0
      fi
    done
    return 1
  }

  # Wait up to 5s for the device to appear (udev race at boot)
  for _ in $(seq 1 50); do
    if DEVICE_PATH=$(resolve_device); then break; fi
    sleep 0.1
  done

  if [ -z "${DEVICE_PATH:-}" ]; then
    echo "Power button '$DEVICE_NAME' not found" >&2
    exit 1
  fi

  exec evtest "$DEVICE_PATH" | while read -r line; do
    if [[ "$line" == *"KEY_POWER"* && "$line" == *"value 0"* ]]; then
      handheld-fake-suspend power
    fi
  done
  ```
