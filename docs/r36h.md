# Game Console R36H

Rockchip RK3326 handheld. Also covers the R36S (vertical variant — same internals). Renders directly to the DRM framebuffer via SDL2's KMSDRM backend; no compositor.

Configuration: `handhelds/r36h/`. SoC wiring: `socs/rk3326.nix`.

## Hardware

- **SoC**: Rockchip RK3326 — quad-core Cortex-A35 @ 1.5 GHz
- **GPU**: Mali-G31 MP2 (Panfrost, or the Mali blob)
- **RAM**: 1 GB DDR3L
- **Display**: 3.5" 640×480 MIPI DSI — NV3051D controller (panel varies by unit)
- **Storage**: two microSD slots — slot 1 NixOS boot, slot 2 ROMs (exFAT)
- **Input**: ROCKNIX singleadc-joypad (`r36s_Gamepad`, buttons + dual analog sticks as one device), volume buttons (`gpio-keys-vol`)
- **Audio**: RK817 codec — speaker + headphone jack (speaker driven through the HP path)
- **USB**: dwc2 OTG controller with runtime role switching
- **WiFi**: RTL8723BS — unpopulated on most units
- **Power**: RK817 charger; power button mapped to suspend via logind

## Controls

- **D-pad / Left stick** — navigate EmulationStation menus
- **A** — select, **B** — back
- **Start** — open ES main menu (system info, quit, shutdown)
- **L1 + R1 + Start + Select** — open RetroArch quick menu (in-game)
- **L3 (left stick click)** — DraStic menu (in NDS games)
- **Volume Up / Down** — adjust audio volume
- **Power (short press)** — suspend; **(long press)** — force power off

## Boot

1. Armbian U-Boot (`u-boot-rockchip.bin`, raw sector 64) loads `boot.ini` from the FAT firmware partition
2. `boot.ini` loads the kernel `Image`, `initrd`, and DTB from `/boot`, and applies the panel DTBO
3. NixOS initrd mounts the ext4 rootfs (label `NIXOS_SD`) and hands off to stage 2

Generations use a custom `installBootLoader` (`socs/rk3326.nix`): U-Boot reads fixed paths, so the script copies the active generation's kernel/initrd/DTB to `/boot/Image`, `/boot/initrd`, `/boot/dtb` and points `/init` at the active `toplevel`.

## Display

The R36H ships with random NV3051D panel variants. The DTB uses the ROCKNIX `panel-generic-dsi` driver, which reads init bytes from a `panel_description` device-tree property (extracted from a working ArkOS DTB via ROCKNIX's `importpanel.py`).

The device tree is compiled standalone via the `rk3326-dtb` package (cpp + dtc on `pkgs/rk3326-dtb/rk3326-r36s.dts`), so DTS changes rebuild in seconds rather than requiring a kernel rebuild.

## Input

The RK3326 reads four analog stick axes through a GPIO-controlled 4:1 mux into a single SARADC channel. The out-of-tree ROCKNIX `singleadc-joypad` driver (`pkgs/rocknix-joypad`) handles ADC sticks and GPIO buttons as one input device (`r36s_Gamepad`), so RetroArch sees a single unified gamepad. Mux select lines use the `gpiod` raw API; left-stick axes are inverted via DTS properties.

Autoconfig: `pkgs/retroarch-joypad-autoconfig/autoconfig/udev/r36s_Gamepad.cfg` (vendor `1`, product `4488`).

## GPU picker

Both Panfrost (default) and the Mali blob are built as one generation set, mali being a specialisation of the panfrost base. Hold **Volume Down** at power-on to boot mali; otherwise panfrost loads. The picker runs in initrd, queries `gpio-keys-vol`, and repoints `/sysroot/init` to the chosen specialisation's toplevel before the closure is resolved.

```nix
handheld.gpu.driver = "panfrost";
handheld.gpu.specialisation.enable = true;
handheld.gpu.specialisation.picker.enable = true;
```

## USB OTG

The dwc2 controller switches role at runtime via the kernel `usb-role-switch` class. The DTS sets `dr_mode = "otg"` with `role-switch-default-mode = "peripheral"`, so the device boots in gadget mode (SSH over USB ethernet). Host mode works for USB audio dongles.

```bash
# Switch to host (USB peripherals)
echo host   > /sys/class/udc/ff300000.usb/device/usb_role/ff300000.usb-role-switch/role
# Switch to gadget (SSH)
echo device > /sys/class/udc/ff300000.usb/device/usb_role/ff300000.usb-role-switch/role
```

A udev rule makes the role-switch attribute writable by the `users` group so scripts launched from ES can toggle it. The port is one role at a time.

## What works

- EmulationStation game browser (GBZ35 Mod theme) with RetroArch cores + DraStic for NDS
- Display (640×480, Panfrost GLES, brightness via sysfs)
- Unified gamepad (buttons + dual analog sticks)
- Audio (PipeWire, auto-switches between speaker and USB audio, volume buttons)
- Battery level in the ES menu
- USB OTG role switching (gadget ethernet for SSH, host mode for peripherals) and USB audio
- PortMaster (mali GPU mode; works on panfrost but slower)
- NixOS generations over SSH; GPU mode switch via Volume Down hold
- Suspend/resume, shutdown/reboot from the ES menu
- Second SD card for ROMs; saves/states on the roms card survive reflash

## What doesn't

- WiFi (no hardware on most units)
- Brightness hotkeys (adjust via ES Display Settings)
